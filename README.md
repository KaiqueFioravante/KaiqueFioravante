Meu processo normalmente parte de um problema real e evolui em ciclos:

**problema → requisitos → decomposição → implementação assistida por IA → testes → auditoria → correções → validação**

Uso IA de forma intensiva para acelerar desenvolvimento e análise, mas trato o resultado como software que precisa ser **entendido, testado e validado**, e não simplesmente como código gerado automaticamente.
